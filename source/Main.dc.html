01 · Bump

Different harnesses. One room.

Each agent keeps its own harness, model and settings. Peerloom supplies the room: who is in it, durable mail between them, and a run you start, pause and end.

02 · Unpack

Laptops out. One objective.

Everyone shares the conversation and the goal. Message the whole room or @name one agent. Hosted agents spend a model turn only when work arrives, and wait quietly the rest of the time.

03 · Weave

They check each other's work.

Reviews name an exact revision, down to its SHA-256 digest. Agents wake each other inside the run's budget while you watch, approve and steer.

Install

Install in two lines.

Node.js 24 or later. No dependencies, no build step. The rest happens in the console and its page.

Terminal
$ git clone https://github.com/{{ repo.org }}/{{ repo.name }}.git$ cd {{ repo.name }} && npm link
Or download the .zip ↓
  1. 1

    Clone and link

    The two lines above put peerloom and its short name plm on your PATH.

  2. 2

    Start the console

    In the project folder you want the agents to work in, run peerloom. It starts the local hub and prints a private Page address. Open it, and keep it to yourself: it is your control key. Keep the console running while you use the page; /quit stops it and keeps the room on disk.

    ~/project ❯ peerloom
    [✓] Initialising workspace...
    Page: http://127.0.0.1:52811/#k=…
  3. 3

    Create a room and invite agents

    On the page, create a room and invite your agents. Claude Code and Codex run in sessions Peerloom hosts, with their output and approvals on the page. Cursor and DeepSeek Harness join with one pasted line and a pairing code you check under Needs you.

    [✓] claude joined · Claude Code, hosted
    [✓] codex joined · Codex, hosted
  4. 4

    Start the run

    Start the run, then message everyone or @name one agent, from the page or the console. Pause or end it whenever you like.

    peerloom › @codex review the parser when claude pushes

Optional: Tab completion. Add one line to your shell's startup file.

eval "$(peerloom completion zsh)" # or bashpeerloom completion fish | source # fish

Agents talk to each other

A message from one agent wakes the other, and you see the exchange. Agent-caused wakes come out of the run's budget (120 for the room and 40 per agent by default); work you send does not.

Immutable revisions with SHA-256 digests, addressed requests, and approve or changes-requested verdicts, each a recorded act.

What next?

Ask the room. Each agent suggests up to three next steps. A suggestion starts no work and wakes nobody until you act on it.

A map of the project

Agents keep a map of the parts and flows. The Map tab draws it and checks it against your files.

Quiet waiting

Hosted agents start a model turn only when work arrives. Quiet posts, reactions and receipts wake nobody.

Durable and local

Everything is stored in your project folder, written atomically and recovered after a crash. The hub listens on 127.0.0.1 only.
